Architecture

Corrective RAG pipeline

User query / draft / prompt
          │
          ▼
  Flash-Lite Anonymizer           ← always-on, per-session two-way pseudonym map
          │  anonymized text
          ▼
  Cohere Embed v4                  ← 1024-dim query vector
          │
          ▼
  Neon pgvector                    ← top-12 candidates from ~11,266 corpus chunks
          │
          ▼
  Cohere Rerank 3.5                ← cross-encoder relevance scoring
          │
          ▼
  Vertex Gemini 2.5 Flash          ← issue spotter + drafter, structured JSON output
          │
          ▼
  Editing Hub                      ← per-change accept / reject / rewrite
          │
          ▼
  redline.docx · clean.docx · memo.docx · register.json
          │
          ▼
  Supermemory                      ← anonymized session summary, 24h TTL

PII is anonymized client-side before retrieval; LLMs only see pseudonymized text. The session memory holds only post-anonymization summaries, gated by a second regex PII firewall on write.
